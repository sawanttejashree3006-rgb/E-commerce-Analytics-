E-commerce Sales Analytics – Excel Project

📌 Project Overview

The E-commerce Sales Analytics project is designed to analyze sales data using Microsoft Excel. This project helps understand sales performance, profit trends, product demand, and customer purchasing patterns through data analysis and interactive dashboards.

🎯 Project Objectives

- Analyze total sales and profit.
- Identify top-selling products and categories.
- Compare sales performance across different cities.
- Analyze order status and payment methods.
- Create interactive dashboards for better business decision-making.

🛠️ Tools & Technologies

- Microsoft Excel
- Excel Formulas
- PivotTables
- PivotCharts
- Slicers
- Data Cleaning
- Data Visualization
- Interactive Dashboard

📊 Key Performance Indicators (KPIs)

- Total Sales
- Total Profit
- Total Orders
- Total Quantity Sold

📈 Dashboard Features

- Sales Analysis by Product Category
- City-wise Sales Analysis
- Monthly Sales Trends
- Payment Method Analysis
- Order Status Analysis
- Top-Selling Products
- Interactive Filters and Slicers

🔍 Key Analysis

This project focuses on identifying sales trends, understanding product performance, comparing city-wise revenue, and evaluating profitability. The analysis helps businesses identify opportunities to improve sales and make data-driven decisions.

💡 Skills Demonstrated

- Data Cleaning and Preparation
- Excel Formulas and Functions
- PivotTables and PivotCharts
- Dashboard Creation
- Data Analysis and Visualization
- Business Insights and Reporting

✅ Conclusion

The E-commerce Sales Analytics project demonstrates how Microsoft Excel can be used to transform raw sales data into meaningful business insights. The interactive dashboard provides a clear overview of sales performance and supports better business decisions.
